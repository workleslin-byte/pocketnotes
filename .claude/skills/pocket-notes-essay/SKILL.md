# Pocket Notes Essay Skill

## What this skill does

Produces essays for pocketnotes.in that read as if written by a human with a decade of professional writing experience. The process is two-stage, sequential, and non-negotiable. Every sentence is checked against 15 anti-AI rules before output. A reference audit prevents duplicate citations across the essay catalogue.

---

## BEFORE WRITING ANYTHING

### Step 0 — Ask questions and wait

Do not begin writing until you have answers to:

1. What is the essay's core argument in one sentence?
2. Who is the reader? (What do they already believe that this essay challenges?)
3. What should the reader understand at the end that they did not understand at the start?
4. Are there specific anecdotes, personal stories, or product details the user wants included?

If the user provides raw copy or a draft, read it fully before asking. Extract what you can infer from the draft, then ask only what remains unanswered.

### Step 0.5 — Reference audit

Before researching, list every reference already used across previously written essays. Check the conversation history and any essay files in the project. The rule is absolute: **no reference may appear in more than one essay.** If Hemingway's first-draft quote was used in "The First Page Rule", it cannot appear in "Catch First. Edit Later." Find a different writer, a different study, a different historical example that makes the same point.

## STAGE 1 — Academic flesh-out

**Role:** Act as a literature academician and note-taking specialist from an Ivy League institution.

**Purpose:** Add scholarly weight, named citations, craft-tradition voices, and historical detail to the raw argument. Every claim must be grounded in a specific named source.

### Rules for Stage 1

1. **Research before writing.** Use web search to verify every citation, find the original source, and recover contextual detail that makes the reference richer than the shorthand version. (Example: The Hemingway quote is not from Hemingway directly -- it was recorded by Arnold Samuelson in Key West in 1934 and published posthumously in 1984. That detail matters.)

2. **Name every source.** No vague attributions. Not "researchers suggest" or "studies show." Name the researcher, the year, the publication, the institution. If you cannot name it, do not cite it.

3. **Keep the narrative tight.** Do not branch into adjacent topics. Every paragraph advances the essay's single argument by one move. If a paragraph could be removed without breaking the argument's logic, remove it.

4. **Prefer the craft tradition over academic research.** Writers talking about their own process (Greene, Forster, Lamott, Hemingway, Plath, Darwin's notebooks) carry more weight in this brand than psychology papers. Use research to support, not to lead.

5. **External links belong in the body.** Link to the source where it appears -- Goodreads for books, journal URLs for papers, Wikipedia for historical context. Not as footnotes. Inline, as part of the sentence.

6. **Do not add images.** Image selection is a separate task. The essay is text only.

## STAGE 2 — Anti-AI rewrite + syntactic surprise

**Purpose:** Rewrite every sentence against the 15 rules below and apply the syntactic surprise technique. This stage produces the final output.

### The 15 Anti-AI Rules (95% compliance required)

**RULE 1 — NO NEGATIVE PARALLELISM**
Ban: "It's not X -- it's Y" and all variants. Write the positive claim directly.

**RULE 2 — NO "NOT X. NOT Y. JUST Z." COUNTDOWN**
Ban: Stringing multiple negations before a reveal. State the point.

**RULE 3 — NO FALSE RANGES**
Ban: "From X to Y" where X and Y are not on a real scale with a genuine middle.

**RULE 4 — NO GRANDIOSE STAKES INFLATION**
Ban: Inflating any argument to world-historical significance. Write at the actual scale.

**RULE 5 — NO SELF-POSED RHETORICAL QUESTIONS IMMEDIATELY ANSWERED**
Ban: "The result? Devastating." State observations as declarative sentences.

**RULE 6 — NO EMPTY FILLER TRANSITIONS**
Ban: "It's worth noting," "Importantly," "Interestingly," "Notably." Connect with logic.

**RULE 7 — NO INVENTED COMPOUND CONCEPT LABELS**
Ban: Coined abstractions like "the supervision paradox," "the friction divide." Describe directly.

**RULE 8 — NO ANAPHORA ABUSE**
Ban: Repeating the same sentence opening in quick succession without earned literary purpose.

**RULE 9 — NO FALSE SUSPENSE TRANSITIONS**
Ban: "Here's the kicker," "Here's where it gets interesting." State the observation.

**RULE 10 — NO PATRONISING ANALOGIES**
Ban: "Think of it as..." / "It's like a..." unless genuinely more precise than the plain statement.

**RULE 11 — NO "THE TRUTH IS SIMPLE" ASSERTIONS**
Ban: Claiming something is "simple," "clear," or "obvious." Do not announce significance. Prove it.

**RULE 12 — NO LISTICLE IN A TRENCH COAT**
Ban: "The first... The second... The third..." as paragraph openers disguising a list as prose.

**RULE 13 — NO SUPERFICIAL "-ING" APPENDS**
Ban: Ending sentences with "...highlighting its importance" / "...reflecting broader trends."

**RULE 14 — NO VAGUE ATTRIBUTIONS**
Ban: "Experts argue," "industry reports suggest." Name the expert or drop the claim.

**RULE 15 — NO UNICODE DECORATION**
Ban: Unicode arrows, smart/curly quotes, special characters. Use straight ASCII. Em dashes acceptable.

### The 5% margin

The margin exists only for:
- Proper nouns or technical terms that canonically use unicode
- Direct quotation where altering the text would be dishonest
- Cases where all rewrite options produce a factually inaccurate sentence

The margin does NOT cover convenience, stylistic preference, or the claim that one instance is acceptable.

### Syntactic surprise rule

At least three times per essay, close a paragraph or sentence in a direction the reader would not predict from its first half. The weight shifts to an unexpected word or clause. The surprise must be earned by the argument -- it lands as more true than the predictable close would have been.

**Examples from produced essays:**

- "The pristine one on the shelf, waiting for thoughts worthy of its pages, is not a kept thing. It is a cancelled one." (Reader expects "is not being used" -- gets "cancelled")
- "Quality came later, at a desk, after sleep, after return. What the pocket notebook solved was proximity -- and proximity, as it turned out, was the whole system." (Reader expects a list of what the notebook solved -- gets the entire system collapsed into one word)
- "The chaos on those pages was not something Darwin tolerated on the way to clarity. The chaos was where the clarity came from." (Reader expects "was part of the process" -- gets the chaos repositioned as the source)

## STRUCTURAL TEMPLATE — The Bible Essay

The structural reference for all Pocket Notes essays is:
`/essays/why-your-notebook-should-never-be-organised`

Match these properties exactly:

### Title
- H1 uses an `<em>` tag on a key phrase for italic emphasis
- Example: `<h1>Why Your Notebook Should <em>Never Be Organised</em></h1>`

### Standfirst
- One or two sentences beneath the title
- States the argument without hedging
- Sets up a tension the body resolves
- Is NOT a summary -- it is a provocation

### Body paragraphs
- Average 60-100 words per paragraph
- No paragraph exceeds 120 words
- Each paragraph advances the argument by one move
- No paragraph restates the previous one in different words

### Pull-quote
- One per essay, inside a `<blockquote>` tag
- Pulled from the body copy, not from an external source
- Must work as a standalone statement
- Sharp, unexpected, the sentence that earns isolation

### Sign-off
- Format: `-- Pocket Notes, [Month] [Year]`

### Section-closing line
- 5-7 word imperative or declaration above the shop CTA
- Distils the essay's argument into one instruction
- Examples: "Messy pages. Clear thinking." / "Marked pages. Working notebook."

## VOICE RULES (non-negotiable)

### Pronouns
- First person plural ("we") for shared human behaviour
- Third person for historical figures
- Second person ("you") only in the essay's final instruction/close

### Rhythm
- Short sentences land the argument. Longer sentences carry the evidence.
- Alternate between the two. No three long sentences in a row.
- No sentence begins with "And" or "But" as a stylistic tic.

### Endings
- The essay ends on a short sentence or very short paragraph
- The final line does not summarise. It closes a door.

### Banned words and phrases
Never use: "elevate," "seamless," "unleash," "next-gen," "premium," "innovative," "made with love," "ink and intention," "No app no battery no subscription"

Never start a sentence with an abstract noun.

Never use motivational or self-help register.

Never announce the significance of a point. Prove it or drop it.

### Voice model
Steve Jobs (short sentences, action-led) + David Ogilvy (every word earns its place). Frank, unhurried, slightly wry. Not self-help. Not inspirational. Not stationery-shop charm.

## PROCESS SUMMARY — The exact sequence

```
1. Read the user's raw copy or brief fully
2. Ask clarifying questions. Wait for answers.
3. Run reference audit against all prior essays
4. Research: web search for every citation, verify sources, find richer detail
5. STAGE 1: Flesh out with academic/craft-tradition weight
   - Named sources only
   - Tight narrative, no branching
   - External links inline
6. Present Stage 1 to user for review
7. STAGE 2: Full anti-AI rewrite
   - Check every sentence against all 15 rules
   - Apply syntactic surprise (minimum 3 instances)
   - Match structural template from bible essay
8. Present Stage 2 as final output
9. If building a Claude Code prompt for HTML replacement:
   - Include the bible essay URL as structural reference
   - Include all 15 rules in the prompt
   - Include the syntactic surprise rule
   - Specify every HTML element to touch and every element to protect
   - Include the complete new copy verbatim
```

## WHAT NOT TO DO

- Do not skip Stage 1 and go directly to Stage 2. The academic weight must be added before the anti-AI rewrite, not after. Reversing the order produces essays that are clean but thin.
- Do not reuse a reference from another essay. Find the equivalent from a different writer, study, or historical example.
- Do not add images or image suggestions unless explicitly asked.
- Do not write a Substack opening paragraph in the same voice as the website essay. Substack requires a more personal, first-person, scene-setting or admission-based opening. The website essay can start with the argument directly.
- Do not produce the Claude Code prompt without having the user review the essay copy first. The prompt is the last step, not the first.
